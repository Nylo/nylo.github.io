Configurazione Firebase richiesta

Inserisci la configurazione Web Firebase nel codice di questo file, abilita Firebase Authentication anonima e crea un Realtime Database. Applica queste regole al database. Il codice stanza autorizza chiunque lo conosca, quindi condividilo solo con i partecipanti; queste regole non impongono un limite numerico ai membri:

{
  "rules": {
    "rooms": {
      "$room": {
        "hostUid": {
          ".write": "auth != null && !data.exists() && newData.val() === auth.uid"
        },
        "members": {
          "$uid": {
            ".write": "auth != null && $uid === auth.uid && !data.exists() && newData.val() === true && root.child('rooms').child($room).child('hostUid').exists()"
          }
        },
        "state": {
          ".read": "auth != null && root.child('rooms').child($room).child('members').child(auth.uid).val() === true",
          ".write": "auth != null && root.child('rooms').child($room).child('members').child(auth.uid).val() === true"
        }
      }
    }
  }
}
