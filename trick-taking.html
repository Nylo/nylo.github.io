Importa da CSV / Google Sheets

Esporta il tuo Google Sheet in formato CSV (File → Scarica → CSV), poi incolla il contenuto qui sotto oppure carica il file.

  1. La prima riga deve essere l'intestazione.
  2. Colonne riconosciute: Titolo, Players, Best in, Playing time, Must-follow, Trump, Prediction, Rules, Played, Status, Notes
  3. I dati esistenti non vengono cancellati: i giochi con lo stesso titolo vengono aggiornati.

🃏 Accesso admin

Inserisci la password per sbloccare la modifica della collezione.

⚠ Elimina collezione

Stai per eliminare tutti i giochi dalla collezione. Questa operazione è irreversibile e sovrascriverà anche il file su GitHub.

Scrivi ELIMINA per confermare:

⚙ Configura sync GitHub

I dati verranno salvati come trick-collection.json nel repo Nylo/netlify-site (branch main).
Il token viene salvato solo nel localStorage di questo browser, non viene mai trasmesso ad altri.

Per creare un token: github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → seleziona solo repo.
